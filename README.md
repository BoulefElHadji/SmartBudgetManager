This document provides a quick overview and guide to using the SmartBudget Manager workbook.

      What it does ?
SmartBudget Manager is an Excel workbook to help you track your monthly budget. Input your income and expenses and the workbook automatically calculates your balance, compares your spending against your budget, provides a chart of expenses by category and lets you know when you are over budget.

      What you need ?
•Microsoft Excel 2016, 2019, 2021 or Microsoft 365 (or compatible application).
•SmartBudget_Manager.xlsx file. No installation No connection to the internet No macros needed.

    How to get started ?
1.Open SmartBudget Manager.xsls
2.Open Categories sheet and adjust monthly budget for each category as needed
3. Open the Transaction sheet. Enter the date and description in the first empty row.
4.Select Type (Income or Expense) and Category from the drop-down list and type the amount in the Income or Expense column.
5. Open the Dashboard sheet to view your balance, budget status and chart.

    Some note you should know
•Use one column per transaction (income or expense) and not the both.
•Only rows 4 to 50 of transactions are counted. Totals add up all months so keep one file per month.
•Save your file regularly (Ctrl+S).
